Travel Mate

Tech Stack: JavaScript, React, HTML, CSS, exchange-api

A React-based web application using modular, reusable components to plan, save, and manage travel itineraries. Includes multi-page navigation using React Router. Incorporates a third-party exchange REST API with asynchronous data fetching and state updates.
